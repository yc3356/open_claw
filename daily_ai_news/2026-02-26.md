# AI每日新闻 - 2026-02-26

## 1. Google发布Gemini 3.1 Pro模型，ARC-AGI-2基准测试超越OpenAI和Anthropic
Google DeepMind发布Gemini 3.1 Pro预览版，在ARC-AGI-2基准测试中获得77.1%的成绩，是上代3 Pro（31.1%）的两倍多，同时超过Anthropic Opus 4.6（68.8%）和OpenAI GPT-5.2（52.9%）。该模型专为解决复杂问题设计，支持动态SVG生成、实时数据可视化等高级功能。
[来源链接](https://www.ifanr.com/1655423)

## 2. 阿里千问3.5登顶Hugging Face开源大模型全球榜首
2月24日，全球最大AI开源社区Hugging Face公布新一期榜单，阿里最新开源的原生多模态模型千问3.5登顶全球榜首。该模型总参数3970亿仅激活170亿，性能媲美Gemini 3，Token成本约为其5%。榜单前十中有8款来自中国团队。
[来源链接](https://www.stdaily.com/web/gdxw/2026-02/25/content_476371.html)

## 3. Anthropic发布负责任扩展政策3.0版本
Anthropic发布RSP 3.0，这是其用于缓解AI系统灾难性风险的自愿框架的第三次更新。新政策将公司计划与行业建议分离，引入前沿安全路线图，并要求每3-6个月发布风险报告。Anthropic承认预设能力阈值比预期更模糊，政府行动进展缓慢。
[来源链接](https://www.anthropic.com/news/responsible-scaling-policy-v3)

## 4. Meta与AMD达成超600亿美元AI芯片合作协议
Meta与AMD宣布扩大战略合作，签署为期五年、价值约600亿美元的AI芯片采购协议。Meta将购买约10%的AMD股份，这是继OpenAI与AMD合作后的又一大客户。首批千兆瓦级部署预计2026年下半年开始，采用定制AMD Instinct MI450芯片。
[来源链接](https://www.theguardian.com/technology/2026/feb/24/meta-amd-deal-chipmaker-ai-bubble-facebook)

## 5. DeepSeek拒绝向美国芯片厂商提供最新旗舰模型

[来源链接](https://www.reuters.com/world/china/deepseek-withholds-latest-ai-model-us-chipmakers-including-nvidia-sources-say-2026-02-25/)

## 6. Anthropic推出Claude Code Security安全扫描工具
Anthropic发布Claude Code Security预览版，该工具可扫描代码库中的安全漏洞并建议针对性补丁。使用Claude Opus 4.6，团队在开源代码库中发现超过500个存在数十年的漏洞。该工具面向防御者，通过多阶段验证流程减少误报。
[来源链接](https://www.anthropic.com/news/claude-code-security)

[来源链接](https://www.reuters.com/sustainability/society-equity/canada-tells-openai-boost-safety-measures-or-be-forced-by-government-2026-02-25/)

## 8. Claude Code被发现存在多个安全漏洞可导致远程代码执行
网络安全研究人员披露Anthropic Claude Code存在多个漏洞，包括CVE-2025-59536（CVSS 8.7）和CVE-2026-21852（CVSS 5.3），可导致远程代码执行和API密钥泄露。攻击者可通过恶意仓库配置在用户打开项目时执行任意命令。
[来源链接](https://thehackernews.com/2026/02/claude-code-flaws-allow-remote-code.html)

## 9. OpenAI正式发布GPT-5系列模型
